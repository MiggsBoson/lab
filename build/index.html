Build something

The lab is a sandbox for small, novel web experiences and tools. Anyone can add one, and you don't need permission to start.

1. Get Claude Code

Install Claude Code on your computer (Windows, macOS or Linux) and open it in a folder where you keep projects.

2. Paste this

Set me up to build in The lab, a sandbox website for small web experiments and tools: https://github.com/MiggsBoson/lab (live at https://miggsboson.github.io/lab/).

Read https://raw.githubusercontent.com/MiggsBoson/lab/main/CONTRIBUTING.md and follow its "Getting started" steps for my computer: install anything missing, help me make a GitHub account if I need one, sign me in, fork and clone the repo, and open the local preview. Explain each step in a sentence, wait for me whenever I need to click, sign in or choose something, and ask before posting anything on GitHub.

Then ask what I'd like to make, build a first version with me as a new experiment following "Your first experiment", and send it as a pull request. Finally, ask whether I want direct access, and if I do, open an access request.

3. Make something

Claude Code installs anything missing, helps you make a GitHub account if you need one, sets up your own copy of the lab and opens it on your computer. Then it asks what you'd like to make, builds a first version with you, and sends it as a pull request. Once that's merged, your experiment is live here for everyone.

About 20 minutes the first time. You'll be asked before anything is posted on GitHub.

What makes a good lab experiment

  • Small and a bit odd. One idea, done in an afternoon.
  • Something strangers do together, like Tug of war, Jam or Fridge magnets.
  • Or a tool someone would actually use, like Evidence Lab.
  • Works on a phone. Plain HTML, CSS and JavaScript, with nothing to install.

Stuck for ideas? The suggestion board on the home page shows what people are asking for.

Rather do it by hand? Every step the prompt takes is written out in CONTRIBUTING.md.
